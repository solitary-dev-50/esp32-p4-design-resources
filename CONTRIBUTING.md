# Contributing

Contributions are welcome when they improve accuracy, traceability, or practical usefulness.

## Good contributions

- newer official Espressif links;
- corrections based on the latest datasheet or errata;
- verified Fusion 360 workflows;
- scripts that fetch official source files without republishing unclear third-party content;
- independently checked package or pin-mapping notes;
- purchasing information that clearly states date, region, and source.

## Evidence required

For technical corrections, include the official source URL and document version or access date.

For ECAD/MCAD files, include:

- original author/source;
- license;
- exact chip/order code;
- package and revision covered;
- what was checked against the datasheet;
- whether the file has been used on fabricated hardware.

## Do not submit

- vendor PDFs copied without redistribution permission;
- community files with unknown authorship;
- claims that a footprint is "verified" only because it looks correct;
- unverified chip availability or pricing presented as permanent;
- private contact, order, payment, or customs information.

## Pull-request checklist

- [ ] Links open successfully.
- [ ] Exact part number is stated.
- [ ] Revision-specific information is identified.
- [ ] Third-party license and attribution are preserved.
- [ ] No official affiliation is implied.
