# ESP32-P4 Official Resources

Official Espressif document index:

https://documentation.espressif.com/en/documentList?s=ESP32-P4&eol=false

Recommended reading order:

## 1. Datasheet

Use the datasheet for:

- pin definitions
- package information
- electrical characteristics
- power requirements
- boot and strapping information

## 2. Hardware Design Guidelines

Use this for:

- power supply design
- decoupling capacitor placement
- crystal circuit
- flash/PSRAM connection
- PCB layout recommendations

## 3. Reference Designs

Reference boards are useful for checking:

- complete power tree
- component selection
- placement strategy
- routing examples

## 4. Errata and Chip Revision Documents

Always check the exact silicon revision before starting a new design.

## ECAD references

Espressif maintains official KiCad libraries:

https://github.com/espressif/kicad-libraries

These are useful references for footprint and symbol verification.
